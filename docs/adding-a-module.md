# 占術の追加手順

1. 採用する流派の規則を文書化する(暦、日付の境界、表記など)。
2. `src/modules/<id>/index.ts` に `DivinationModule` を実装する。`requires` に必須の入力を書くと、不足時はその体系だけ保留される。
3. 共通の計算が必要なら `Services` に追加する。既存モジュールは書き換えない。
4. `src/modules/registry.ts` に1行追加する。必要時にのみ読み込まれる。
5. 出典付きの照合ケースをテストに追加し、合格後に `validationStatus` を `cross_checked` にする。
6. `contentKeys` を定義する。本文が未入稿でも「解説準備中」で動く。

計算結果を推測で作らないこと。入力不足や計算不能のときは別方式へ切り替えず、保留として返す。
