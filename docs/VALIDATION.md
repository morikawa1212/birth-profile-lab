# 検証の記録

実施日 2026-11-05。入力はすべて合成データです。再現は `npm test`(外部照合は `tests/external.test.ts`)。

## 確認できたこと
| 対象 | 参照先 | 結果 |
|---|---|---|
| 10天体の地心視黄経 | NASA JPL Horizons(40時点、1900〜2026年) | 最大差 0.57秒角(天王星)、他は0.42秒角以下。平均約0.09秒角の一定のずれは座標系の定義差と見られる。ライン幅3,375秒角に対して無視できる |
| 遺伝子易経の全スフィア | Gene Keys 公式プロフィール 1例(オーナー本人の提供、値はここに記載しない) | 全12項目の鍵とラインが一致 |
| 64の鍵の黄道上の位置 | Gene Keys 公式の Astrological Coordinates 表 | 全64鍵が一致 |
| ASC、MC、プラシーダスのカスプ | Swiss Ephemeris を使わない独立の計算式(合成300地点) | 0.005度以内 |
| ラヒリのアヤナムサ | Swiss Ephemeris 文書の定義値、スピカの位置 | 定義値と章動の範囲内で一致、スピカは約180度 |
| 数秘術 | 方式の出典ページの計算例3件 | 全件一致 |
| 日本の夏時間 | IANA の規則、法律の実施期間 | 4年分の開始・終了が一致。1951年の終了日のみ資料が食い違うため画面で確認を促す |
| TS 実装の全項目 | Python 試作(合成1,000件) | 全件一致 |
| 全ゾーンの時刻変換 | Python zoneinfo(25,978件) | 全件一致 |

## まだ確認できていないこと
- **公式プロフィールの他の例:** 一致を確認したのは1例のみで、資料 §10 の目標100例には未達。夏時間や海外の例は `docs/validation/manual-cases.md` で手作業で照合できる。
- **外部の占星術ソフトとの一致:** 西洋(astro.com など)、インド(Jagannatha Hora など)の出力とは比べていない。天体位置、アングル、アヤナムサの個別の検証から、差が出にくいと考えている。
- **1970年より前の海外の時刻:** IANA のデータ自体に誤りがありうる。画面で確認を促す。
- **スマホ実機:** オーナーの端末で動作を確認したが、速度の計測はしていない。
